## 2. Policy, since direction is limited

If hire, fire and policy are the only levers on staff, policy has to carry the per-round
decision that manual placement used to. The shape that fits §5.2's "overwork can be correct"
is a **choice with a drawback**, set per round from the build screen, never a slider with one
right setting. A first list, for the corporate slice only:

| Policy | Raises | Costs |
| --- | --- | --- |
| Overtime: off / on / crunch | Output this round | Fatigue rate; carried fatigue into next round (§5.2's persistence) |
| Drinking party | Morale | Money; fatigue the next morning |
| Morning exercise | Recovery rate | Morale |
| Hiring stance: graduates / experienced | Cheap, tireless / skilled | Unskilled / dear, impatient |

Policy is content. Each business type brings its own set (a conbini's would be about opening
hours and stock orders), which is one more test of "content, not code".
